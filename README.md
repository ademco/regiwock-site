# regiwock-site

Regi's (@regiwock) portfolio and booking site. Built with Astro + Tailwind and deployed on Cloudflare Pages.

```bash
npm install
npm run build        # → dist/
npm run new -- music "Song Title" "https://open.spotify.com/track/..."
npm run list
```

See [CLAUDE.md](./CLAUDE.md) for the full project guide.
